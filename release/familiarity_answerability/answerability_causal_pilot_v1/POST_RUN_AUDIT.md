# Post-Run Audit: Answerability Causal Pilot v1

**Audit date:** 2026-08-04

**Frozen machine decision:** `not_supported`

**Scientific interpretation:** `not_evaluable_as_confirmatory_causal_test`

## What completed

The pinned Gemma 2 2B workflow ran on a free-Colab T4. Validation selected
layer 18 and multiplier 1.0. Both protected splits completed their full
registered schedules, producing 432 atomic evidence receipts. The one-use
evaluator then opened both endpoints.

| Split | Primary mean effect | 95% bootstrap interval | Strongest control | Strongest-control effect |
|---|---:|---:|---|---:|
| Unseen entities | 0.1812 | [0.1738, 0.1891] | Wrong layer | 0.4388 |
| Unseen templates | 0.1659 | [0.1569, 0.1745] | Label-shuffled direction | 0.1659 |

The frozen evaluator returned `not_supported` for both splits because the
lower confidence bound for the primary-minus-strongest-control contrast was
not positive. Across the 144 primary-versus-baseline prompt rows, the
intervention changed log-probability margins but changed no greedy output.

## Control defect

The post-run audit compared the vectors stored in
`validation/causal_evaluation_seal.json`. The 2,304-dimensional primary and
label-shuffled vectors were bit-for-bit identical:

```text
array_equal: true
L2(primary - shuffled): 0.0
max_abs(primary - shuffled): 0.0
cosine_similarity: 1.0
```

The original implementation paired a permuted set of bound activations with
the complete unbound set and then averaged every unit. Permuting a complete
set does not change its mean, so the resulting control was algebraically
guaranteed to equal the primary mean-difference direction. The exact equality
on the template split is therefore an implementation artifact, not evidence
that an independent shuffled direction reproduced the effect.

## Interpretation

The generated `results/result.json` remains immutable and correctly records
what the preregistered evaluator returned. The stricter scientific status is
nevertheless `not_evaluable_as_confirmatory_causal_test`, because a mandatory
null control was not independent. Removing that control after seeing outcomes
would be an invalid post-hoc rescue.

Even without the defective control, the entity split's wrong-layer effect was
substantially larger than the primary effect. The run therefore does not
support a layer-specific answerability mechanism. It establishes that the
intervention pipeline executed and that several directions changed the local
code-versus-`UNKNOWN` margin; it does not establish causal specificity of the
registered answerability direction.

## Future-only correction

The implementation now constructs the label control by swapping bound and
unbound labels within a balanced half of training units, which sign-flips
their paired deltas while preserving unit clusters. Sealing also fails closed
if the shuffled vector is exactly equal to the primary vector. Regression
tests cover both properties.

This repair applies only to a future preregistered replication. The opened
entity and template units cannot be reused for confirmatory claims, and the
repair does not alter or rescue this study.

The published receipts were generated by the pre-fix implementation bound in
their manifests. The corrected source code was not used to generate or
reanalyze those receipts.
