# Domain Docs

This repository uses a single domain context.

Before exploring or changing the research pipeline, read:

- `CONTEXT.md` at the repository root, when present;
- relevant architectural decisions under `docs/adr/`, when present;
- the active preregistration, amendment, or execution plan for the study.

Use the terms defined in `CONTEXT.md` consistently in code, tests, issues, and
reports. If a proposed change conflicts with an ADR or a frozen study document,
surface the conflict instead of silently overriding it.

Missing domain documents are not an error. Create or extend them only when a
term or decision needs to be recorded.
