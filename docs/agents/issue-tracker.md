# Issue Tracker: GitHub

Issues and research implementation tickets live in this repository's GitHub
Issues. Use the `gh` CLI from this checkout so the remote is inferred
automatically.

## Conventions

- Create issues with `gh issue create`.
- Read issues and comments with `gh issue view <number> --comments`.
- List work with `gh issue list`.
- Record implementation outcomes in an issue comment before closing it.
- Pull requests are not a request or triage surface for this repository.

When a skill says to publish a specification or ticket, create a GitHub issue.
When a skill asks for the relevant ticket, read that issue and its comments.
